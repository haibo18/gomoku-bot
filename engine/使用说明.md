# Rapfi 五子棋引擎（C:\五子棋\engine）

2026-11-16 安装 · 版本 250615（2025-06-15 发布，官方最新）

## 一、里面有什么

| 文件 | 作用 |
|---|---|
| `pbrain-rapfi-windows-sse.exe` | **本机要用的就是它**。SSE 指令集版引擎（本机 CPU 无 AVX2，见下节） |
| `pbrain-rapfi-windows-avx2.exe` 等 4 个 | 高指令集版本，本机跑不起来（0xC000001D 非法指令），留给换机后用 |

| `config.toml` | 引擎配置（默认 32MB 置换表、1 线程、坐标不转换） |

Linux / macOS 版可执行文件也一并留着了（换机、上云主机时能直接用）。

## 二、为什么只能用 SSE 版

本机 CPU：`Intel Xeon E5-2680 v2`（Ivy Bridge，10 核 20 线程，2.8GHz），只有 AVX、**没有 AVX2 / AVX512**。

实测三个版本各自启动：

| 引擎 | 退出码 | 结论 |
|---|---|---|
| `pbrain-rapfi-windows-sse.exe` | 0，正常输出落点 | 可用 |
| `pbrain-rapfi-windows-avx2.exe` | 3221225501（0xC000001D，STATUS_ILLEGAL_INSTRUCTION） | 直接崩，不可用 |
| `pbrain-rapfi-windows-avx512.exe` | 3221225501 | 直接崩，不可用 |

SSE 版实测性能（15 路无禁手，3 秒/步）：

| 线程 | 速度 | 搜索深度 | 3000ms 内节点 |
|---|---|---|---|
| 8 线程 | 583K nps（另一局 1070K） | 20–33 层 | ~1.7M |
| 1 线程 | 63K nps | 17–32 层 | ~0.19M |

即 8 线程约有 9 倍加速，10 核机器建议 `--threads 8`～`16`。

## 三、协议：它不是 UCI

Rapfi 走的是 **Piskvork / Gomocup 协议**（`pbrain` 前缀，比赛管理器如 Piskvork、c-gomoku-cli 用它）。UCI 是国际象棋协议，五子棋引擎里没有真正的 UCI 实现；Rapfi 只在配置里提供 `message_mode = "ucilike"`（输出风格接近 UCI），协议本身不变。

`rapfi_client.py` 就是这个协议的封装，你只需要给盘面、拿落点，不用手写协议。

### 实测踩到的 3 个协议细节（都已在客户端里处理）

1. **`INFO` 必须发在 `BOARD` 之前。** 顺序错了（先 BOARD 再 INFO TIMEOUT_TURN），时限会被忽略 —— 实测有一次没设住，一路算到 124 秒、22 层才给答案。
2. **`BOARD` 里的颜色：`1` = 引擎自己一方，`2` = 对手。** 让两方各有一条活四、看它补哪条：它只补 `1` 那条（返回 `2,5`），之后发 `TURN` 也不改变这一点。
3. **输出坐标是 0 基 `x,y`**（如 `6,6`），`x` 为列、`y` 为行；它自己在 `MESSAGE` 里用 `G7` 这种字母记法。客户端已统一换算成 `A1..O15`。

## 四、怎么用

```powershell
cd C:\五子棋\engine

# 示例：天元一子，引擎执白接走，2 秒
python rapfi_client.py --demo

# 给盘面（黑白交替，首子为黑；也可用 H8:B 显式指定颜色）
python rapfi_client.py --moves "H8:B,I8:W,G8:B,F8:W" --engine-color W --time 3000 --threads 8

# 只要机器可读结果
python rapfi_client.py --moves "H8,G7" --json
```

输出直接带手机坐标：

```
推荐落点 : G7  → 棋盘坐标 (6, 6)  → 手机像素 (470, 1069)
adb 命令 : adb shell input tap 470 1069
```

像素坐标取自同一套实测值（`五子棋棋盘坐标.紧凑版.json` 里的 `axes.x_int / y_int`），1024×2412 这台机器上误差 ≤2px。

Python 里调用：

```python
from rapfi_client import RapfiEngine
eng = RapfiEngine(threads=8, time_ms=3000)      # rule=1 即 15 路无禁手
res = eng.analyze([("H8", "B"), ("I8", "W")], engine_color="W")
print(res["move"], res["pixel"])                 # G7 (470, 1069)
```

## 五、参数与规则对照

| 参数 | 取值 | 说明 |
|---|---|---|
| `--rule` | 0 / 1 / 4 | 0=无禁手任意盘，1=15 路无禁手（**手机 App 用这个**），4=有禁手 |
| `--time` | 毫秒 | 每步上限；网络对局建议 2000–4000（留出 adb 点击和对手动画时间） |
| `--threads` | 整数 | 本机 8 线程实测 583K–1070K nps |
| `--engine-color` | B / W | 引擎执哪一方 |
